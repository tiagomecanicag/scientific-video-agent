# Scientific Video Agent | PT / EN

A bilingual workflow for turning scientific papers into explanatory videos, with nine stages and researcher approval checkpoints.

Um fluxo bilingue para transformar artigos cientificos em videos didaticos, com nove etapas e validacoes do pesquisador.

## Start here / Comece aqui

- [English guide and setup instructions](README_EN.md)
- [Guia em portugues e instrucoes de uso](README_PT.md)

Download this repository using **Code > Download ZIP**, extract it, and follow the guide for your language. The agent runs in a compatible local environment; this repository distributes its instructions and supporting files.

Baixe este repositorio em **Code > Download ZIP**, extraia os arquivos e siga o guia do seu idioma. O agente funciona em um ambiente local compativel; este repositorio distribui suas instrucoes e arquivos de apoio.

## Workflow / Etapas

1. Understand the paper / Entendimento cientifico.
2. Define the protagonist, audience and narrative / Protagonista, publico e narrativa.
3. Plan segments, script and duration / Tapes, roteiro e duracao.
4. Establish visual identity / Linguagem visual.
5. Approve starting and ending images / Validacao das imagens.
6. Review the animatic / Revisao do animatic.
7. Produce and approve each segment / Producao e aprovacao de cada tape.
8. Assemble and review / Montagem e revisao final.
9. Prepare publication materials and obtain approval / Pacote de divulgacao e autorizacao.

Default output: **1080 x 1920 pixels, vertical 9:16**. Change only when explicitly requested during review.

Formato padrao: **1080 x 1920 pixels, vertical 9:16**. Alterar somente mediante pedido explicito durante a revisao.

Media generation requires suitable tools and any associated accounts or credits. Researcher review remains necessary for scientific accuracy.

A geracao de midia depende de ferramentas adequadas e das respectivas contas ou creditos. A revisao do pesquisador continua necessaria para garantir a fidelidade cientifica.
